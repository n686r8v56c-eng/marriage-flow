# Marriage Flow — React UI

연보라색 모바일 UI의 결혼 준비 및 관계 프로젝트 관리 앱입니다.

## 실행

1. Node.js 18 이상 설치
2. 이 폴더에서 `npm install`
3. `npm run dev`
4. 터미널에 표시된 주소 열기

빌드: `npm run build`  |  정적 배포 결과: `dist/`

## 포함 기능

- 홈: 세 영역 진행률과 오늘 일정
- 만남 확대/홍보: 프로젝트 생성, 카테고리별 체크리스트, 메모, 결과 건수
- 작전 일정: 실행 단계에서 일정 생성; 프로젝트·작전별 필터
- 관계 발전: 상대별 독립 카드, 7단계 체크리스트, 메모, 완료일 자동 기록
- 관계 일정: 완료 기록/예정 일정, 상대별 필터
- 브라우저 로컬 저장, JSON 백업/복원

데이터는 `localStorage`에만 저장됩니다. 기기 간 동기화나 사용자 인증은 포함되지 않습니다.

**주의:** 프로젝트 로딩 후 JSX 파일을 직접 수정하려면 `src/main.jsx`를 수정하세요. `src/style.css`에 스타일이 있습니다.
